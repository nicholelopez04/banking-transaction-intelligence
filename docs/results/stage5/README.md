# Accepted independent synthetic evidence

The 16 original CSV/JSON/report files in this directory are byte-identical copies from the accepted Stage 5 study. `evidence_manifest.json` records their SHA-256 hashes, source paths and original inventory hash. No final cases were regenerated to prepare this presentation.

Start with `REPORT.md`; `all_case_metrics.csv` contains all 160 model/case/policy records. `scenario_summary.csv` and `scenario_variability.csv` retain every scenario. Native decisions and equal-budget ranking are distinct policies. Equal-budget reviews total exactly 8,000 per pipeline. Neither model passed the hypothetical synthetic screening targets or is production-ready.

The sealed protocol embeds the earlier proposal's historical “awaiting approval” status. Subsequent explicit approval authorized the completed study; this is preserved historical text, not an indication that the saved results are provisional. The explicit once-generation instruction recorded in the protocol superseded the earlier double-generation proposal.

Labels denote synthetic interventions, not verified real-world fraud or verified legitimate outcomes. Rows and events differ. Undefined precision/recall must not be interpreted as successful detection.

Full raw cases, feature matrices, row-level predictions, fitted artifacts, source snapshots and test records are preserved in a verified local archive. They are deliberately excluded from this compact public viewer bundle. The public snapshot supports metric inspection and display verification; it is not a standalone reproduction package for fitting or rerunning the accepted experiment. Historical model and protocol hashes remain recorded for provenance.
